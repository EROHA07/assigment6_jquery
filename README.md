## About the project

This is my simple portfolio website. I used HTML, CSS and jQuery to add buttons, effects and animations.

## Tasks

### Task 0 - Setup
I added jQuery using a CDN and used `$(document).ready()`. The console prints "jQuery is ready!".

### Task 1 - Selectors and CSS
I added my name and a short introduction. I used tag, ID and class selectors, changed text and CSS, and made light and dark theme buttons.

### Task 2 - Show, Hide and Toggle
I added an About Me section with a status message and facts. The buttons show, hide or toggle the content.

### Task 3 - Fade Effects
I added two pictures and buttons for `fadeIn()`, `fadeOut()` and `fadeToggle()`.

### Task 4 - Slide Effects
I added three headings with panels. I used `slideUp()`, `slideDown()` and `slideToggle()`.

### Task 5 - Add and Remove Skills
The list has four skills at the start. I used `append()`, `prepend()` and `remove()` to edit the list. Empty skills are not added.

### Task 6 - Attributes
I added a link and a button that changes its URL using `attr()`.

### Task 7 - Form
I added name and email inputs. The text below the form updates while typing using `val()` and `text()`.

### Task 8 - Animation
I added three skill bars. The `animate()` method changes their width when I click the button.

## How to run

1. Download the project.
2. Open `index.html` in a browser (or with Live Server in VS Code).
3. Check that the buttons and animations work.

An internet connection is needed to load jQuery from the CDN.
